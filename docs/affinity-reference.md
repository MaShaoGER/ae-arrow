# Affinity 箭头形状实查（2026-10-05）

通过 computer-use / @oai/sky 检查本机 Affinity 中文界面，在现有箭头形状上依次切换全部端点；最后恢复右端箭头、成比例、长度 50%、内偏移 0%。视图调整为 28% 以看到完整图形。

| 样式 | 可编辑参数（除成比例） | 实查默认值 |
| --- | --- | --- |
| 无 | 无 | — |
| 箭头 | 长度、内偏移 | 50%、0% |
| 有刺 | 长度、厚度 | 50%、10% |
| V 形 | 长度、V 形长度 | 50%、50% |
| 圆、方框、菱形 | 大小 | 50% |
| 方形尾部 | 长度、缩进大小 | 50%、25% |
| 三角尾部 | 长度、缩进大小 | 50%、0% |
| 内半圆 | 大小、缩进大小 | 50%、0% |
| 外半圆 | 大小 | 50% |

关闭成比例时，50% 自动显示为 15%，画布几何保持不变；原物体长 1370.3 px、高 412.2 px。由此推断成比例时横向尺寸相对整体高度，关闭时相对整体长度。AE 实现将整体高度映射到“端点高度”，整体长度映射到源路径弧长。这是路径端点版本的对应实现，不宣称和 Affinity 逐像素等同。

AE 时间线没有公开的属性展开及滚动接口。实机尝试 RevealExpressionErrors (2731)、RevealAllModifiedProperties (2771)、Reveal in Timeline (2536)、临时关键帧、延迟调用及窗口焦点切换；原生“显示表达式错误”菜单也未滚动到目标。未将这些不可靠的绕行实现保留在交付中。当前按钮只精确选中路径，面板显示完整层级，并提示时间线连按 S 显示所选属性、X 滚动到图层。可靠的一键展开及滚动尚未实现。定位不改写表达式及关键帧。命令号参考 [命令 ID 工具源码](https://github.com/hyperbrew/after-effects-command-ids/blob/master/json/2025.json)。

FFX 参数记录的名称字段限 35 字节（UTF-8）。构建脚本检查长度，避免长中文标签破坏二进制。0.5 使用独立 matchName，0.4 的菜单索引及几何保留在独立兼容模块。
