## 可见交互

实机打开了 0.3 面板，中文分区、颜色预览、三个参数标签、路径点选择及补齐按钮正常显示。点击色块打开 AE 原生选色框，显示吸管、RGB/HSB、十六进制输入和预览；确认改色后，箭头与面板色块同步变化。

在独立演示合成 `AE Arrow 0.3 UI Verification` 中选中“路径点 · 2”，实际按 Shift + 右方向键使其 Position **[0,0] → [10,0]**，合成中的折点同步右移。实机直接点击原生线宽控件的重置后，箭头线宽同步变化。原生功能测试另直接写 Position / Slider 并检查表达式求值；它们不等同于鼠标拖动测试。

鼠标拖动多次尝试未得到可靠的路径点 Position 变化，**合成窗口的鼠标拖动未通过自动化验收**。不能据此声称完整鼠标操作已经验证。可用面板选择单个空对象，再使用原生 Position 数值或方向键编辑。

尚未验收连续拖动帧率、高 DPI 命中、多箭头性能、完整拖动单步撤销、停靠及工程保存重开。此版为 JSX 面板，没有编译过的 `.aex`。旧版测试记录见 `docs/legacy/TEST_REPORT.md`。
