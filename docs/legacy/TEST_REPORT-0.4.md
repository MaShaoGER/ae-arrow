模拟测试新增单空对象的源坐标与偏移叠加，以及生成参数中的整数样式编号和肩部位置。真实 PNG 检查验证直线连接处 690 个中心线像素最小 Alpha 为 255，曲线轮廓为单个连通区域；仅代表这些样例。

## 可见交互

实机显示 0.4 小型操作面板和效果控件的中文线身、起点、终点、高级分组。新演示合成 `AE Arrow 0.4 UI Verification` 有三个控制点，共五层。

选中单个控制点后实际按 Shift+右方向键，Position 的表达式结果从 `[500,180]` 改为 `[510,180]`，原始偏移从 `[0,0]` 改为 `[10,0]`，箭头折点同步改变，且无表达式错误。记录见 `test-results/visible-interaction-0.4.json`。

鼠标拖动尝试没有得到可靠的控制点偏移变化，**鼠标拖动未通过自动化验收**。这不等同于已确定鼠标不能拖动；已验证的交互是方向键与 Position 数值/关键帧。尚未验证多箭头性能、持续帧率、完整撤销、停靠、保存重开和高 DPI 命中。当前不是 `.aex` 插件。
