# AE Arrow Live 0.3.0

面向 Windows / After Effects 2026。入口为 `dist/AE Arrow.jsx`，单文件即可运行。此版将样式改成箭头图层上的原生效果控件，并为源路径每个顶点生成可编辑空对象。实机结果见 [TEST_REPORT.md](TEST_REPORT.md)。

## 使用

1. 运行 `dist/AE Arrow.jsx`，或放入 `Support Files/Scripts/ScriptUI Panels` 后从“窗口”菜单打开。
2. 用钢笔画开放路径，在时间线选中具体的“路径”属性，再点击“从选中路径创建”。也支持开放蒙版路径。
3. “路径与编辑”区用于创建、读取、编辑源路径及选择路径点；“外观”区设置颜色和虚线；“线身 / 起点 / 终点”标签设置各部分样式。
4. 点击“颜色：”后的预览色块，打开 AE 原生选色框，可用吸管、RGB 或十六进制输入。确认后预览与箭头同步更新。
5. 点击“选择箭头图层”，按 F3 打开效果控件。直接调整 `AA` 滑块，合成中的箭头实时更新；也可使用面板滑块。效果控件中修改后，点击“刷新参数”更新面板显示。
6. 在“路径点”下拉框选择全部或某个顶点，点击“选择空对象”。编辑对应“路径点 · N”的 Position，可以改变箭头路径，也可以设置位置关键帧。使用方向键可微调。
7. “编辑源路径”仍可修改原节点及贝塞尔切线。源路径及源层的动画持续生效，空对象的位置作为其上的附加偏移。
8. 添加路径顶点或删除控制空对象后，点击“生成 / 补齐路径点”；已有点的偏移和关键帧保留，重复点击不会重复生成。

## 效果控件

| 原生控件 | 含义 |
| --- | --- |
| `AA Width` | 线身粗细 |
| `AA Start / End Type` | 起点、终点样式编号 |
| `AA Start / End Length` | 连接肩部位置 |
| `AA Start / End Angle` | 头尖夹角，单位为度 |
| `AA Start / End Width` | 头部高度 |
| `AA Color` | 颜色 |
| `AA Dashed / Dash / Gap` | 虚线开关、长度及间隔 |

`AA Start / End Depth` 由夹角与头部高度计算，保留其表达式；改变高度时夹角保持不变。圆点、方块等没有尖角的样式，角度控制纵向深度。两端各支持无、实心箭头、空心箭头、开放尖角、燕尾、圆点/椭圆、方块、菱形。

`AA Source` 与 `AA Point N` 是图层引用。生成的表达式负责实时更新，关闭面板后仍生效。

## 路径点与旧版

每个顶点生成一个可编辑空对象和一个隐藏、锁定的跟随框架。框架读取原顶点的位置，空对象初始 Position 为零，因此生成时不会改变现有路径。移动空对象只改变相应顶点，保留原贝塞尔切线向量。新箭头不再生成旧版八个样式控制/框架层。

0.2 实时箭头可通过“读取箭头”继续编辑，并生成路径点。读取后显示的转换按钮可以将无动画的旧样式控制转换成原生滑块，保留当前外观；存在相关关键帧或自定义表达式时会拒绝转换，原控制方式仍可使用。0.1 静态箭头需要从路径重新创建，旧入口保存在 `dist/legacy`。

## 当前边界

- 支持二维开放路径、2–256 顶点、嵌套组位移/旋转/缩放及二维父层。暂不支持斜切、三维、闭合路径和参数化矩形/椭圆。
- 空对象按顶点序号对应。插入、删除或重排节点后，应检查已有偏移与关键帧是否仍属于预期节点，再补齐路径点。
- 源路径/组通过名称绑定；不要重命名、迁移或删除它们。源图层改名和排序不影响绑定。
- 默认输出层单位变换。定位请编辑源层、源路径或路径点；不要改变跟随框架或空对象的父级。
- 面板保护已有关键帧或表达式的参数；动画请在 AE 原生控件中编辑。滑块拖动尚未合并为单次撤销。
- 原生空对象的位置、关键帧和方向键编辑已验证；合成窗口鼠标拖动未通过本次自动化验收。
- 急弯、大头部和极短路径尚需更多样例；未测多箭头/高节点工程的持续帧率、资源占用、停靠和保存重开。

## 开发

`scripts/build.ps1` 组装单文件。`live-math.jsxinc` 为几何核心，`live-host.jsxinc` 安装表达式和控制，`live-ui.jsxinc` 提供面板。

```powershell
& ./scripts/build.ps1
node tests/live.test.cjs
node tests/live-host.test.cjs
node tests/core.test.cjs
& ./scripts/build-live-tests.ps1
& 'E:\Programs\Adobe After Effects 2026\Support Files\AfterFX.com' -r 'D:\project\ae-arrow\test-results\ae-live-tests.jsx'
```

AE 异步写出报告和 PNG，完成后运行 `tests/render-check.py` 检查连接。测试创建独立合成，删除其临时层及未使用素材；可见演示合成保留供检查。后续方向见 [BUILD_ROADMAP.md](BUILD_ROADMAP.md)。
