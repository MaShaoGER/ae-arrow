# AE Arrow · ScriptUI 测试版

一个面向 After Effects 2026（26.x）的箭头生成脚本。当前版本为 **0.1.0 测试版**：已在 Windows 的 AE **26.0x67** 实机执行，完成核心和原生图层测试。测试范围、性能数据与未验证项目见 [TEST_REPORT.md](TEST_REPORT.md)。

## 运行

入口文件：`dist/AE Arrow.jsx`。它已包含全部模块，使用时不需要携带 `src` 文件夹，也不需要安装 Node.js 或第三方 AE 插件。

临时运行：在 AE 中选择 **文件 → 脚本 → 运行脚本文件…**，打开 `dist/AE Arrow.jsx`，显示浮动面板。

固定到工作区：把这个单文件放入当前 AE 安装目录的 `Support Files/Scripts/ScriptUI Panels` 文件夹，重启 AE，再从 **窗口** 菜单打开 `AE Arrow`。具体安装目录以你的 AE 2026 安装位置为准，本项目没有自动复制到 AE 目录或改变 AE 设置。

ScriptUI 脚本运行及停靠方式见 [Adobe 官方脚本说明](https://helpx.adobe.com/after-effects/desktop/automate-in-after-effects/automate-animation/scripts.html)。

## 使用流程

1. 打开一个合成，在“线身”“端点”标签调整参数，或在“预设”中载入内置样式。
2. 点击 **创建箭头**，在合成中心生成一个原生形状图层。用 AE 的 Position、Rotation、Scale 摆放它。
3. 选中已有箭头，点击 **读取选中**，修改后点击 **更新选中**。切换到另一个箭头时重新读取。
4. 如需减少点击，读取后勾选 **松手更新已读取箭头**。拖动滑条仅改变面板预览，松手后写入图层一次。输入数值、切换类型、改变颜色在确认时提交。
5. 预设页可以把当前样式保存为 JSON，或打开已有 JSON。载入预设只改变面板参数，需点击创建或更新。

错误和提示显示在面板底部；提示文字的完整内容也在鼠标悬停说明中。

## 当前实现

- 起点与终点独立选择：无、实心三角、空心三角、开放尖角、燕尾、圆点/椭圆、方块、菱形。
- 两端分别设置长度、宽度和燕尾凹陷；不适用参数自动禁用。
- 直线和单段三次贝塞尔曲线；正弯曲量向上弯，负值向下弯。
- 实线或虚线，线宽、端帽、虚线长度/间隔、两端留空、统一颜色。
- 12 个内置样式以及单个 JSON 预设保存/打开。
- 原生图层的创建、参数读取与更新；图层备注中保存带版本参数。
- 样式更新保留图层变换、父子关系、图层外部效果及非管理内容。
- 工具内部出现手动改动、关键帧或表达式时停止覆盖，可读取原参数后新建箭头。
- 短路径自动缩小端点，保留原始头部参数；留空超过路径长度时显示错误。

## 尺寸与预览

“总长度”是未变换时起终点的水平间距，曲线实际弧长可能更长。尺寸以图层局部像素计；图层 Scale 会连同线宽一起缩放。圆点的长宽不同会生成椭圆。空心和开放头部的描边宽度与线身一致。

面板采用抽样的 ScriptUI 绘制作为示意预览；AE 使用真实贝塞尔形状路径。缩小预览中的极细虚线按最小显示长度近似，端帽/接合显示也可能与 AE 有细微区别。最终以 AE 输出为准；12 个内置样式的实机渲染见 `test-results/style-gallery.png`。

静态生成不添加表达式，也不使用后台轮询。颜色和虚线样式不触发曲线几何重新计算。图层属性仅在值变化时写入；滑条拖动不会反复重建图层。

## 编辑保护与存储

每个图层包含 `__AE_ARROW_V1__` 管理分组，内部有 `Body`、`Start`、`End` 三个分组。元数据位于图层 comment 中的 `[[AE_ARROW_V1:...]]` 分段；其他用户备注保留。不要删除工具标记或直接编辑管理分组，除非希望转成手工图形。

更新前对管理内容指纹和动画属性进行检查。读回的是上次工具提交的参数，不是任意手绘路径的反向解析。图层复制后可以独立读取；只按当前选中图层与宿主图层 ID 定位，不依靠图层名字。

创建和更新分别使用一个 undo group；更新的单步撤销/重做已通过实际 AE 菜单验证。写入失败时尝试恢复原参数，不能确认完整恢复时提示使用 AE 撤销；中途故障的回滚及多级撤销仍待测试。

仅预设文件的保存/读取涉及文件访问。若 AE 阻止它们，可在偏好设置中开启“允许脚本写入文件和访问网络”。创建和更新图层本身不依赖网络。

## 开发与重新构建

```powershell
powershell -NoProfile -File .\scripts\build.ps1
```

构建只合并源码，输出带 UTF-8 BOM 的单文件脚本，不启动 AE，也不执行测试。

| 文件 | 职责 |
| --- | --- |
| `src/core.jsxinc` | ES3 参数模型、安全 JSON 编解码、几何、内置预设 |
| `src/host.jsxinc` | AE 创建/读取/更新、差异写入、备注元数据、编辑保护 |
| `src/ui.jsxinc` | ScriptUI 控件、示意预览、松手提交 |
| `scripts/build.ps1` | 合并并输出 `dist/AE Arrow.jsx` |
| `BUILD_ROADMAP.md` | 原始开发路线及当前实施记录 |
