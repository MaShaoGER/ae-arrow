# AE Arrow 0.1.0 测试记录

日期：2026-10-05。此版本可以开始试用，尚未达到原路线中的完整性能验收门槛。

## 环境与结果

- Windows；After Effects **26.0x67**；真实 ExtendScript 引擎 **4.5.6**。
- CPU：AMD Ryzen 9 9955HX；GPU：NVIDIA GeForce RTX 5070 Ti Laptop GPU（同时存在 AMD 集显）。未测量 GPU 负载或内存占用。
- 核心测试：**12 项通过，0 项失败**；Node.js v24.18.0。包含 128 种直线/曲线端点组合和 2000 组边界参数。
- AE 原生测试：**22 项通过，0 项失败**，原始结果见 `test-results/ae-native-tests.json`。
- 可见界面检查：浮动面板正常显示中文、预览和控件；实际点击创建/更新，以及调整长度、切换虚线的预览刷新均通过。
- 12 种内置样式已在 AE 实际渲染，PNG 文件在脚本返回后生成，已检查文件时间和图像内容。

## 覆盖的行为

| 范围 | 验证内容 |
| --- | --- |
| 生成 | 12 种预设、64 种起终点搭配、短箭头、曲线及虚线反复切换 |
| 更新 | 同一原生图层更新，读回参数一致；颜色修改不改变路径几何 |
| 保留 | Position、Scale、Rotation、父层、用户备注、非管理分组与外部效果 |
| 定位 | 同名图层及复制图层独立定位；两个初始位置应用同样样式后保持各自位置 |
| 保护 | 锁定、手动修改路径、手动启用虚线槽、关键帧、表达式、拖动时切换对象均拒绝错误覆盖 |
| 面板 | 宿主中的控件布局与按钮回调；拖动回调不写 AE，松手回调才提交一次 |
| 可见交互 | 实际点击创建、滑条调整、点击更新；长度与虚线预览重画 |
| 撤销/重做 | 从 AE 编辑菜单单步撤销更新：939.69 → 400；单步重做：400 → 939.69；图层 ID 与数量保持一致 |

原生自动测试中的面板回调检查采用隐藏窗口；可见绘制另行通过实际面板操作检查，二者没有混算成更多自动用例。

## 修复内容

1. **虚线无法写入**：AE 按名称查找及按索引枚举都会返回尚未启用的虚线槽，不能据此判断它已添加。改为检查槽的 `canSetExpression`，显式启用后重新获取属性再写值；关闭虚线时只移除已启用的槽。指纹同时包含启用状态，手动开启默认值虚线也会被发现。
2. **预览停在旧图形**：AE 的 Panel/Image 没有原实现调用的 `notify` 方法，异常被吞掉后只显示首次绘制。改为可绘制 Image 控件，隐藏后重新显示以请求重画；刷新异常会显示提示。长度和虚线变化已可见验证。
3. **属性更新开销**：合并动画保护与内容指纹遍历；根据上次提交参数跳过未变化的几何/绘制属性，减少重复查找及读写。保留覆盖保护和撤销分组。
4. **测试误报**：AE 返回的二维图层变换可能包含三个坐标分量，改为比较真实读值；Shape 顶点 getter 返回副本，手动编辑用例改为显式赋回。PNG 输出完成晚于脚本返回，改为请求后再检查文件，不以立即存在判断失败。

## 性能测量

最终宿主耗时以 `test-results/ae-native-tests.json` 中的 `timings.nativeUpdateMs` 为准。本次采用 1920×1080、30 fps 的二维合成，35 个图层，单个箭头连续修改线宽 100 次，测量整个 `Host.update()`，包括检查、几何处理、属性写入、元数据和撤销分组，**不包含 AE 屏幕重绘**。

最终一轮：**中位数 136 ms，P95 147 ms**，100 次更新、35 个图层。初始实现曾测得中位数 190 ms、P95 242 ms（29 个图层）。两轮图层数量和进程状态不同，不能把差值当作严格对照实验。

Node 核心生成的中位数约 0.03 ms，仅代表 Node 中的校验和几何计算，不能用于推断 AE 引擎速度或 UI 帧率。

当前策略是拖动时只画面板预览，松手后更新 AE 一次。尚未测量真实拖动帧率、松手到合成显示的完整延迟、长时间使用占用、4K 或 100 个箭头场景；不能宣称实时合成调参达到 60 fps。

## 重现方式

```powershell
& .\scripts\build.ps1
node .\tests\core.test.cjs
& .\scripts\build-native-tests.ps1
```

在 AE 的“文件 → 脚本 → 运行脚本文件”中执行 `test-results/ae-native-tests.jsx`。测试创建自身的临时合成及素材并清理，报告写入脚本所在目录；不会自动关闭或保存当前工程。PNG 要在脚本结束后检查。也可使用本机已安装的 `AfterFX.com -r` 启动脚本；`AfterFX.exe -r` 本次未稳定返回报告。

可见交互用 `tests/ae-ui-setup.jsx` 建立单独测试合成并打开分发脚本；`tests/ae-ui-observe.jsx` 读取该合成的图层数量、ID 和备注，供比对撤销/重做。UI 辅助脚本的路径按本工作区编写。

自动化原始记录位于 `test-results/core-tests.json` 和 `test-results/ae-native-tests.json`；更新、撤销、重做的备注快照分别位于 `test-results/ui-after-update.txt`、`ui-after-undo.txt`、`ui-after-redo.txt`。首次失败结果另存于 `test-results/ae-native-initial.json`，仅用于记录修复来源。
