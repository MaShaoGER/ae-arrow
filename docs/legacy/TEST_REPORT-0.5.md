## Affinity 实查与可见检查

使用电脑操控在本机 Affinity 中逐项切换全部 11 个菜单选项，检查各自参数及默认值；见 `docs/affinity-reference.md`。已恢复原来的右端箭头、长度 50%、成比例及内偏移 0%。

AE 演示合成 `AE Arrow 0.5 · Affinity 样式` 将 10 种可见端点排成两列，使用 AE 原生渲染生成 `test-results/affinity-style-gallery.png`。人工查看图像确认默认端点方向和线身连接；尚未逐像素比较 Affinity 的所有参数极值。

实机查看效果控件，确认突出名称“◆ 箭头样式 · 在此调整”位于 AA Source / AA Point 引用下方。路径模块显示源图层及完整分组链。

**路径按钮的一键展开及滚动未通过可视验收。** 当前交付只精确选中路径，并提示时间线连按 S 显示所选属性、X 定位图层。尝试过原生命令、临时表达式及关键帧、延迟调用和窗口焦点切换，未得到可靠结果；交付不包含会临时改写用户表达式的方案。

## 验证边界

AE 伪效果不支持按当前样式动态隐藏参数；专用参数通过名称标明适用样式。Affinity 形状模型映射到曲线路径端点，尚未证明逐像素等同。停靠、工程保存重开、多箭头性能、完整撤销和鼠标连续拖动仍未验收。0.4 的可见控制点键盘移动验证保存在 `docs/legacy/TEST_REPORT-0.4.md`，不作为本次新增的交互验证。
