# AE Arrow 0.6.0

[下载安装包](https://github.com/MaShaoGER/ae-arrow/raw/refs/heads/main/dist/AE%20Arrow%200.6.0.zip) · [安装说明](docs/INSTALL.md)

Windows / After Effects 2026。运行 `dist/AE Arrow.jsx`，单文件内已包含伪效果预设，不需要安装插件、修改 AE 的 XML。独立 `dist/AE Arrow Controls.ffx` 仅供查看控件；它本身不创建箭头。

## 安装为面板

只需复制 `dist/AE Arrow.jsx` 到 AE 的 `Support Files/Scripts/ScriptUI Panels/`，重启 AE 后从“窗口 → AE Arrow”打开，可停靠。此处的重启用于刷新菜单；直接“文件 → 脚本 → 运行脚本文件”无需重启。不要复制整个源码目录，也无需另装 FFX。创建箭头需要在 AE 偏好设置的“脚本和表达式”中启用“允许脚本写入文件和访问网络”，以便把内嵌控件预设写入临时目录。

本机安装位置：`E:\Programs\Adobe After Effects 2026\Support Files\Scripts\ScriptUI Panels\`。详见 [安装说明](docs/INSTALL.md)。

## 三维场景

勾选面板的“创建三维箭头”后，从源路径创建；源图层和输出箭头以及路径点会同步开启三维。源层或其父层已是三维时自动使用此模式。输出层以零位置、零锚点和单位变换作为源图层的子层，路径和控制点用世界坐标转换，避免重复摄像机投影。源层可以隐藏，箭头仍然显示。移动、旋转、缩放和设置 Z 深度请操作源图层，父层动画及摄像机透视持续生效。

这里的箭头是三维空间中的平面形状：路径点的 X/Y 偏移可动画，Z 保持为零；没有挤出厚度，也不连接不同深度的空间节点。平面侧面对着摄像机时会自然变窄。0.5 及之前的箭头不自动改动，请选中原源路径用新版创建三维箭头；旧箭头的样式及点偏移不会自动迁移。

## 使用

1. 用钢笔画开放路径，在时间线选中具体的“路径”或“蒙版路径”属性，点击“从选中路径创建”；三维场景按上面的三维模式创建。
2. 选中箭头图层，按 F3。在效果控件最底部的 **◆ 箭头样式 · 在此调整** 中调整线身、起点、终点，也可直接设置关键帧。内部 `AA Source` 和 `AA Point N` 绑定引用排在样式效果上方；新增／补齐路径点后仍保持这个顺序。
3. 面板的路径模块显示源图层到具体路径的完整层级。“编辑源路径”精确选中该路径属性，支持嵌套形状组和蒙版路径，保留路径关键帧和原有表达式。时间线面板连按 `S` 显示所选属性，按 `X` 滚动到图层；当前 JSX 尚未实现可靠的一键展开及滚动。
4. 选择某个路径点空对象，通过原生 Position 数值或方向键修改偏移、设置位置关键帧。源路径顶点和贝塞尔切线仍可以继续编辑或动画。
5. 新增顶点或删除控制点后点击“生成 / 补齐路径点”。已有点的偏移和关键帧保留，重复补齐不会重复生成图层。

## 样式

| 分组 | 参数 |
| --- | --- |
| 线身 | 粗细、颜色、虚线、虚线长度、间隔 |
| 起点 / 终点 | 样式、端点高度、成比例、长度 / 大小 |
| 按样式调整 | 箭头内偏移、有刺厚度、V 形长度、方形尾部缩进、三角尾 / 内半圆缩进 |

两端各支持 **无、箭头、有刺、V 形、圆、方框、菱形、方形尾部、三角尾部、内半圆、外半圆**，顺序与 Affinity 箭头形状工具一致。已使用电脑操控逐项检查 Affinity 的样式、参数标签和默认值。两种尾部向线身内侧，内／外半圆使用不同方向的贝塞尔弧。

“端点高度”是 Affinity 形状整体高度在路径端点上的对应尺寸。开启“成比例”：长度 / 大小及 V 形长度以端点高度为基准；关闭：以源路径的完整弧长为基准。默认长度为 50%，即头部深度为高度的一半；圆与方框也能形成椭圆与矩形。有刺厚度、尾部缩进以高度为基准，箭头内偏移以头部深度为基准。两端参数独立。

AE 伪效果无法随着样式切换动态隐藏参数，因此专用参数集中在“按样式调整”中，名称注明适用样式。非当前样式的参数不会改变图形。短路径会缩小端点，以免两端相互覆盖。曲线路径沿端点切线定向，并保持原生三次贝塞尔线身。

`AA Source` 和 `AA Point N` 是内部图层绑定引用，保证图层重排及改名后仍能找到源层和控制点。不要删除或改写这些引用；不要重命名样式效果及源路径／分组。

## 每个路径点只用一个空对象

0.3 的隐藏框架负责读取源位置，可见空对象保存偏移。0.4 将这两步合并在可见空对象的 Position 表达式里：

`最终位置 = 源顶点转换到箭头坐标中的位置 + Position 的原始值`

原始值初始为零，用于保存偏移和偏移关键帧。源层、父层、形状组、源路径动画持续生效；关闭面板后仍生效。表达式只读取源路径，不会读取生成后的箭头路径，因此没有自身循环依赖。

N 个顶点的新箭头需要 N 个控制空对象、一个源层和一个输出层，共 N+2 层；三个顶点从旧版 8 层降至 5 层。Position 显示的是表达式结果，脚本写偏移时需要用表达式前的值。

合成窗口鼠标拖动尚未通过本次自动化验收。已实机验证 Position 数值、位置关键帧及 Shift+方向键操作。请保留 Position 表达式，并保持控制点父级为箭头层。

## 旧箭头

0.4 箭头通过新版面板“读取箭头”后，样式效果会移动到底部并使用突出名称，原样式含义、关键帧和路径点结构保留。点击 **采用 Affinity 端点** 可转换静态旧样式并保留路径点偏移与位置动画；已有样式动画或表达式时拒绝转换。旧空心箭头、开放尖角、燕尾映射到最接近的新样式，转换可能改变端点外形；可用 AE 撤销恢复。新建箭头默认使用 Affinity 模式。

读取 0.3 箭头后，可分别点击“转为伪效果”和“路径点减为单空对象”。转换为伪效果保留静态样式；样式已有关键帧或自定义表达式时拒绝自动转换。合并路径点保留原偏移关键帧；修改过控制点父级、位置表达式或跟随框架时拒绝合并。框架还有其他子层时保留该框架。

0.2 的样式点可先转成原生滑块，再转为伪效果；旧样式动画仍受保护。0.1 静态箭头需要从路径重新创建。

## 当前边界

- 支持二维开放路径和三维源层上的平面开放路径、2–256 顶点、父层和嵌套组位移/旋转/缩放。暂不支持不同 Z 深度的空间曲线、挤出、形状组斜切、闭合路径和参数化矩形/椭圆。
- 控制点按顶点序号对应；插入、删除、重排节点后需检查已有偏移和关键帧的对应关系。
- 输出层保持单位变换；定位请编辑源路径、源层或控制点。三维模式须保留输出层与源层、控制点与输出层的三维开关及父子关系。
- Affinity 风格根据实查形状重新实现；尚未逐像素验证所有参数极值。AE 的曲线路径扩展与 Affinity 的直线形状模型存在差别。
- 已完成六支箭头场景的求值和缓存区往返拖动检查。工程保存重开、连续拖动的精确延迟、完整撤销、停靠、大量箭头的复杂工程及高 DPI 命中仍待验收。
- 截图中的自定义图标栏及操作按钮暂用下拉菜单和小型脚本面板承担。

## 时间线拖动性能修改（已完成首轮实机验证）

当前源码和独立 JSX 包含针对拖动时间线的第一轮优化：单空对象直接提供箭头本地坐标，组变换在一次表达式求值中合并后复用；零切线直线段使用解析弧长换算，曲线采样减少临时数组；各路径只生成自己的部件，“无”端点跳过整条路径的采样和线身生成。没有冻结时间或降低动画帧率。

已有工程中的表达式保存在图层上，仅替换面板文件不会自动改变它们。运行当前 `dist/AE Arrow.jsx`，选中已有箭头，点击“读取箭头”，再点击 **更新 / 优化表达式**。新创建的箭头直接使用新版逻辑。

更新按钮替换工具生成的三个输出路径表达式，并更新能识别的单空对象跟随表达式；保留源路径、样式关键帧、Position 偏移关键帧、图层数量和表达式启用状态。自定义控制点表达式保留；输出路径本身已有关键帧时拒绝更新。修改集中在一个可撤销操作中，安装失败时恢复旧表达式。

已完成 AE 26.0 的原生功能、旧箭头更新、缓存区鼠标往返拖动及图像对比。四种匹配场景的表达式求值中位耗时下降；连续拖动的逐帧延迟尚未精确量化，箭头区域的空闲自动缓存问题也未确认修复。详细结果见 [测试记录](TEST_REPORT.md)。

## 开发与验证

`scripts/build-pseudo.py` 生成控件预设、索引定义及嵌入数据；`scripts/build.ps1` 组装单文件。构建需要 Python，运行时不需要。控件二进制生成器作为独立构建工具保存在 `tools/ffx-builder`，附上游来源和 GPL v3 许可证。

```powershell
& ./scripts/build.ps1
node tests/live.test.cjs
node tests/live-host.test.cjs
node tests/performance.test.cjs
node tests/core.test.cjs
& ./scripts/build-live-tests.ps1
& 'E:\Programs\Adobe After Effects 2026\Support Files\AfterFX.com' -r 'D:\project\ae-arrow\test-results\ae-live-tests.jsx'
```

AE 异步写出结果；确认 `test-results/ae-live-tests.json` 的 `finished` 为 true 后再运行其他 AE 脚本。PNG 连通性检查需带 Pillow 的 Python。详见 [TEST_REPORT.md](TEST_REPORT.md)。0.3 的说明和测试记录保存在 `docs/legacy/*-0.3.md`。
